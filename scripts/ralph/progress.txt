## Codebase Patterns
- Run `npm run build` from `code/` directory for typecheck
- Use `npx tsx scripts/...` from project root to run TypeScript scripts
- Exam types are in `code/src/types/exam.ts` - import them with relative paths in scripts
- Test flow: exam detail page → StartTestSection (timer toggle) → TestClient (quiz engine) → results page
- Quiz results stored in sessionStorage under 'testResults' key for cross-page access
- Server action `saveExamAttempt()` in `code/src/app/actions/examAttempts.ts` saves to database
- Tests: Use vitest, files are `*.test.ts` co-located with source, run `npm run test:run` from `code/`
